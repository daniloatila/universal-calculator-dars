# Voice and image

[Português brasileiro](README.pt-BR.md) · [Observed availability](availability.json) · [Image review capture](reviewed-printed-expression.png)

**Selected image.** In DARS Intelligence, expand **Voice and image** and choose a PNG. Local Canvas code recognizes a single high-contrast line of printed digits, parentheses, a decimal point and the four arithmetic signs. The decoder checks the PNG signature, IHDR dimensions, 1 MiB input limit, 2048 × 512 dimension ceiling and 524,288 pixel ceiling before decoding. It rejects uncertain glyphs and ambiguous segmentations. The user can correct the draft, adopt the expression, validate it and authorize a Rust calculation. Chrome recognized a generated monospace PNG as `2+3`; the real engine returned `5`. A malformed file produced a failure and left calculation unavailable. Handwriting, general text, fractions with stacked layout and multiline proofs are outside this recognizer’s scope. No camera or external OCR service is accessed. [Recognition implementation](../../../apps/web/src/voice-vision.ts) · [Browser tests](../../../apps/web/tests/intelligence.spec.ts)

**Dictation.** The implementation checks the browser’s on-device recognition API and requires the selected language to be already available. An explicit click starts a single final utterance with `processLocally=true`. The session ends on recognition, error, cancellation, panel closure or the 15-second deadline. The transcript is an editable draft. Local recognition in Chrome was “downloadable” for six project locales and “unavailable” for Arabic. Chrome reported no language ready for local dictation in this run. No language pack was downloaded, microphone opened or recognition claimed. [On-device recognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally) · [Language availability](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/available_static)

**Read result.** An explicit click requests speech for a verified result with a locale-matching voice marked `localService`. Chrome exposed two such voices for Brazilian Portuguese and zero for the other six project locales. Voice inventory was observed without playing audio. Acoustic playback and recognition of a physical microphone remain unverified. [SpeechSynthesisVoice](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)

**Alternatives evaluated.** Tesseract.js supports multilingual general OCR via a WebAssembly worker and language data. Windows Media OCR relies on platform capabilities and available languages. The bounded printed-expression recognizer reuses Canvas to keep initial load, model storage and platform requirements small. It does not claim the breadth or accuracy of general OCR. [Tesseract.js](https://tesseract.projectnaptha.com/) · [Windows OCR](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine)

The calculator, opening Intelligence and local OCR operate without querying the speech service. In **Voice and image**, **Check local speech availability** explicitly queries installed components without recording or playing audio.
