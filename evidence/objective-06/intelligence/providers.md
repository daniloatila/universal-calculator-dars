# Provider protocols

[Português brasileiro](providers.pt-BR.md) · [Validation and limits](README.md)

| Provider | Destination and contract | Official reference |
| --- | --- | --- |
| Ollama | Selected literal loopback. Read `GET /api/tags`, then `POST /api/chat` with a chosen model, messages, JSON output, bounded generation and streaming off. Extract `message.content`. Reject cloud aliases, remote metadata and entries without local weight metadata. | [List](https://docs.ollama.com/api/tags) · [Chat](https://docs.ollama.com/api/chat) · [Cloud models](https://docs.ollama.com/cloud) · [OpenAPI](https://github.com/ollama/ollama/blob/main/docs/openapi.yaml) |
| LM Studio | Selected literal loopback. Read `GET /api/v1/models`, check a local GGUF/MLX LLM, then `POST /v1/chat/completions`. Accept a matching model key or loaded instance ID. Extract the first choice’s message. | [Model metadata](https://lmstudio.ai/docs/developer/rest/list) · [Chat completions](https://lmstudio.ai/docs/developer/openai-compat/chat-completions) |
| Compatible local server | Selected literal loopback. Explicit discovery reads `GET /v1/models`. Chat uses `POST /v1/chat/completions` with scalar text content and bounded `max_tokens`. This protocol alone cannot attest the server’s processing location. | [Model list](https://lmstudio.ai/docs/developer/openai-compat/models) · [Chat compatibility](https://lmstudio.ai/docs/developer/openai-compat/chat-completions) |
| OpenAI | Fixed `https://api.openai.com/v1/responses`, bearer header, separate instructions/input, configurable model, `max_output_tokens` and `store:false`. Read a message’s `output_text`. Account retention policies still apply. | [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) |
| Anthropic | Fixed `https://api.anthropic.com/v1/messages`, `x-api-key` and version header, system text, typed messages and `max_tokens`. Read a text block. | [Messages API](https://platform.claude.com/docs/en/api/messages/create) |
| Google Gemini | Fixed HTTPS Google Generative Language host and `/v1beta/models/{id}:generateContent`. Key is passed as a header. Read a non-thought text part from a candidate. | [GenerateContent](https://ai.google.dev/api/generate-content) |

Local ports range from 1024 through 65535. Only `127.0.0.1` and `::1` are valid. Optional model discovery returns up to 256 bounded names and never auto-selects a model. Users can select only destinations documented above. External routes require a known provider, blocking offline mode switched off, an explicitly configured key, a reviewed ticket, HTTPS and eligible public IPv4 resolution. IPv6-only external DNS, private inference servers on a LAN, public CORS proxies and custom cloud endpoints are outside the supported routes. The external client honors system proxy configuration and preserves certificate and hostname verification. [Transport library](https://docs.rs/reqwest/0.13.5/reqwest/struct.ClientBuilder.html)

HTTP 401/403 indicate authentication failure, 402 indicates a cost or payment limit, and 429 indicates rate limiting. Redirects are denied. Malformed and oversized replies cannot reach the computation interface. Provider/model or protocol changes may require updating an adapter. The six serializers and extractors are tested with synthetic responses. Live API calls require separate consent, credentials and any applicable budget.
