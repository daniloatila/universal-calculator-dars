# Compatibilidade

[English](compatibility.md)

| Ambiente | Escopo |
| --- | --- |
| CLI nativo | Toolchain Rust travada e o mesmo contrato financeiro usado pelo navegador |
| Navegador | WASM de produção, sete idiomas, cinco perfis, cache offline preparado e telas móveis |
| Windows x64 | Ativos de produção empacotados no executável Tauri de revisão, com verificação no WebView2 instalado |
| Linux e macOS | Builds e testes no escopo de cada job, registrados na ficha de aceitação |

O registro do executável identifica a versão, o commit, o hash e o estado de assinatura do artefato de revisão.
