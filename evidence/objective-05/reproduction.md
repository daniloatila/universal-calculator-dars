# Reproducing Objective 05

[Português brasileiro](reproduction.pt-BR.md)

1. Use the review-branch delivery for the audit scripts. Build the application from the audited source commit identified in the acceptance ledger. Use the workspace Rust toolchain and a supported Node release. Build with `cargo build --release --locked -p dars-cli`, install the pinned wasm-bindgen CLI using `node scripts/install-wasm-bindgen.mjs`, and run `node scripts/build-wasm.mjs`. On the project Windows host, dot-source `scripts/dev-env.ps1` to use the installed toolchain. The build produces Standard plus 21 tool WASM files.
2. Run `npm ci --ignore-scripts --prefix apps/web`, `npm run build --prefix apps/web`, `npm test --prefix apps/web`, `cargo fmt --all --check`, `cargo clippy --locked --all-targets -- -D warnings` and `cargo test --locked`. The full four-job workflow lists the tracked mathematical and financial regression commands.
3. For native scientific reference comparisons, install the hashed test-only wheels from the two requirements files in `tests/` in an isolated Python environment. Run each `tests/verify-<module>.py` with the CLI executable. Enable `--scipy` for Optimization. Use `node tests/verify-simulation-targets.mjs`, `node tests/check-science-kernel-targets.mjs` and `node tests/check-data-targets.mjs` with the same executable for WASM parity. Additional boundary suites run with the release CLI: `python -B tests/verify-data-import.py <CLI>` checks 55 import contracts, and `python -B tests/verify-optimization-boundaries.py <CLI>` checks 12 optimization and graph boundaries.
4. In `apps/web`, run `npm run test:e2e` to produce the Playwright JSON report. Run `node tests/verify-web-offline.mjs` from the repository root. The scientific Chrome suite exercises math, responsive/RTL layouts, all five resource profiles, data and graph exports, cancellation, recovery, offline operation and directed language changes. The collector uses real per-case artifacts. Keep the report from a single complete run.
5. Run `node benchmarks/science-data.mjs` for table throughput, allocations and exact sums at four sizes. Run the coverage step in the workflow to produce a normalized scientific line report. The coverage denominator and workload are specified in the output.
6. Validate the hosted Windows package with `scripts/verify-science-windows-artifact.ps1`, passing artifact ID, run ID and commit. Run `node scripts/verify-desktop.mjs --objective-05 --exe <candidate>` for the inherited UI checks. Run `node scripts/verify-science-desktop.mjs <approved-0.4.1-exe> <candidate-exe> <verified-receipt> <output-directory>` in the interactive Windows session for the paired measurement. The harness validates hashes and closes its test processes.

The desktop timing, physical memory and system counters depend on the device, WebView2 and background activity. Standard's first navigation and advanced-tool warmed offline execution are distinct scenarios.
