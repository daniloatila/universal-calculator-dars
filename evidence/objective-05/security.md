File bytes stay in the local browser or WebView2 worker and in Rust linear memory until each job ends. The UI keeps a temporary reference for paging or explicit export. Selecting a file, saving a pipeline, exporting a graph and downloading a proof are user actions. The new modules add no native command, filesystem entitlement, remote service, account or analytics destination. The offline tests inspect actual requests and run the warmed tools after network removal. Tauri capability and workflow permissions remain scoped.

The embedded ZIP reader accepts stored or deflated spreadsheet parts. Preflight checks include the compressed file size, entry count, total and individual expansion sizes, safe internal names and worksheet relationships. The reader bounds actual output against the declared part length. XML processing is iterative with a depth budget. DTDs and processing instructions are rejected. Workbook scripts, binary payloads, external links and connections have no execution route. UTF-8 decoding, row width, field length and typed value checks also apply to the local dataset. Table cells render as React text. Protected CSV export neutralizes spreadsheet formula prefixes. Literal export preserves the value when the user chooses that mode.
