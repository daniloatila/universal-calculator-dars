| Change | Reason and verification |
| --- | --- |
| Rust Universal engine and feature-isolated WASM build | Nine advanced modules needed structured, bounded operations under the same CLI and web contracts. Each tool links only its selected feature. The build generates one tool asset at a time. Independent references, parity and isolated asset tests cover the result. [Universal engine](../../crates/dars-universal) · [Tool WASM entry](../../crates/dars-tool-wasm) · [Build](../../scripts/build-wasm.mjs) |
| Ten-entry catalogue and dedicated workspaces | The shell adds localized search and purpose-built controls for expressions, matrices, geometry, base conversion, units and calendars. It loads workspaces on demand and retains temporary drafts within the existing module lifecycle. [Catalogue](../../apps/web/src/module-registry.ts) · [Browser tests](../../apps/web/tests) |
| Advanced runtime resource contracts | Long-running tools use bounded jobs, worker teardown and explicit failure outcomes. Geometry diagrams respond to adaptive rendering budgets. Stage-specific browser and desktop checks cover cancellation, suspension and isolation. [Worker runtime](../../apps/web/src/tool-runtime.ts) · [Geometry verification](geometry/verification.md) · [Benchmarks](benchmarks.json) |
| Cache support for individual module assets | First navigation prepares the core shell and the record viewer shared with Standard, allowing its first offline use. Selected locales and eligible advanced assets are prepared separately. The user can restrict the web page to cached resources. [Cache build rules](../../apps/web/offline-plugin.mjs) · [Offline runner](../../tests/verify-web-offline.mjs) · [Compatibility](compatibility.md) |
| Calculation Proof | A versioned local export/import contract captures provenance, domains, methods and exactness. Standard provides an additional opt-in record API with certified interval information and bounded opaque bindings. Existing Standard evaluator shapes are covered by the baseline suite. [Record contract](calculation-proof/contract.md) · [Baseline map](regression.md) |
| Dependency selection | Scientific and Linear Algebra add reviewed, pinned Rust packages. Date & Time selects the existing Jiff family in the lock and embeds IANA 2026f. Python references are test-only. The Converter uses synthetic dated rate fixtures and a manual offline currency path. [Inventory](dependencies.md) · [Converter limits](converter/limits.md) |
| Audit and reproduction tooling | The workflow builds and tests on three operating systems, and the Ubuntu job adds independent mathematical references and Chromium. Test and benchmark ledgers distinguish local execution, stage snapshots, and the exact cumulative GitHub run. [Workflow](../../.github/workflows/ci.yml) · [Reproduction](reproduction.md) |
