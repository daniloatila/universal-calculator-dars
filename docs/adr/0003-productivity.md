# 0003 · Composition and optional Intelligence

Three primary workspaces share the same 22 Rust engines through a bounded request catalog. Each request binds an operation, validated input, a worker lifetime and a Calculation Proof. Flow and notebook documents store source notation and versioned recipes. Formula definitions pass declarative tests before reuse. Opening a document reads its contents. Running or exporting is a separate action.

Desktop provider traffic passes through the native broker. Disabled is the factory mode. A one-use authorization binds the model, destination and body. Loopback traffic uses numeric IPv4 or IPv6 and a direct local connection. External HTTPS providers retain the platform proxy and TLS validation. Web users can open structured proposals and execute their mathematics locally. The UI renders model explanations separately from Rust results.
